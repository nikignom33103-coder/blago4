# 🤝 Вклад в проект "Благо дарить!"

Спасибо за интерес к нашему проекту! Мы рады приветствовать вклад сообщества.

## 📋 Как внести вклад?

### 1. Сообщить об ошибке 🐛

Если вы нашли ошибку:
1. Откройте GitHub Issue
2. Укажите название проблемы
3. Опишите шаги для воспроизведения
4. Добавьте скриншоты/видео если возможно
5. Укажите версию браузера и ОС

### 2. Предложить новую функцию 💡

1. Откройте GitHub Issue с меткой `feature-request`
2. Подробно опишите идею
3. Объясните, как это поможет волонтерам
4. Предложите реализацию (если есть)

### 3. Отправить Pull Request 📝

#### Подготовка

```bash
# 1. Форкните репозиторий
# (кнопка Fork на GitHub)

# 2. Клонируйте свой форк
git clone https://github.com/ВАШ_ЛОГИН/blago4.git
cd blago4

# 3. Создайте ветку для фичи
git checkout -b feature/my-amazing-feature

# 4. Или для исправления
git checkout -b fix/bug-name
```

#### Разработка

```bash
# 1. Установите зависимости (если нужны)
npm install

# 2. Запустите локальный сервер
python -m http.server 8000

# 3. Сделайте изменения
# Следуйте существующему стилю кода

# 4. Протестируйте в разных браузерах
# (Chrome, Firefox, Safari, Edge)
```

#### Совет по кодированию

```javascript
// ✅ ПРАВИЛЬНО - следуйте существующему стилю
const MyModule = {
    async init() {
        await this.render();
        this.setupEventListeners();
    },

    async render() {
        const contentElement = document.getElementById('pageContent');
        contentElement.innerHTML = `<div>...</div>`;
    },

    setupEventListeners() {
        // Слушатели
    }

// ❌ НЕПРАВИЛЬНО - не следуйте новым стилям
function myFunction() {
    // старый стиль кода

class MyClass {}
// без модульной архитектуры
```

#### Комментарии и документация

```javascript
// Добавляйте комментарии для сложной логики
// Объясняйте "почему", а не "что"

// ✅ ХОРОШО
// Проверяем, активна ли коллекция, перед добавлением в отчет
if (collection.status === 'active') {
    // ...
}

// ❌ ПЛОХО
if (collection.status === 'active') { // проверяем статус
    // ...
}
```

#### Коммиты

```bash
# Используйте понятные сообщения на русском или английском
git commit -m "feat: Добавлена интеграция с Т-Банк API"
git commit -m "fix: Исправлена ошибка при экспорте отчета"
git commit -m "docs: Обновлена документация README"

# Форматы коммитов:
# feat: новая функция
# fix: исправление ошибки
# docs: изменения документации
# style: форматирование кода
# refactor: переработка кода
# test: добавление тестов
# perf: улучшение производительности
```

#### Отправка PR

```bash
# 1. Обновитесь из основного репозитория
git fetch upstream
git rebase upstream/main

# 2. Отправьте в свой форк
git push origin feature/my-amazing-feature

# 3. Создайте Pull Request на GitHub
# - Укажите четкое название
# - Напишите описание
# - Ссылайтесь на связанные Issues
# - Добавьте скриншоты если применимо
```

## 🧪 Тестирование

Перед отправкой PR, пожалуйста:

1. **Браузеры:**
   - [ ] Chrome (последняя версия)
   - [ ] Firefox (последняя версия)
   - [ ] Safari (если есть Mac)
   - [ ] Edge (если есть Windows)

2. **Устройства:**
   - [ ] Десктоп (1920x1080)
   - [ ] Планшет (768x1024)
   - [ ] Мобильный (375x667)

3. **Функционал:**
   - [ ] Форма отправляет данные
   - [ ] Данные сохраняются в Firebase
   - [ ] Навигация работает
   - [ ] Нет ошибок в консоли
