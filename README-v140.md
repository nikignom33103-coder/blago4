# 🎯 Благо дарить! - Портал волонтерской организации

> Полнофункциональная система управления гуманитарной помощью для координации рейсов, финансов, сборов, благотворителей и содействия участникам СВО

**📌 Версия:** 1.4.0 (CRM и профессионализм)  
**📅 Дата выпуска:** 8 февраля 2026  
**📍 Местоположение:** г. Санкт-Петербург  
**🗄️ База данных:** https://blago-a6270-default-rtdb.firebaseio.com/
