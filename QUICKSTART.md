## 🎯 Что это?

**Портал "Благо дарить!"** - система для волонтерской группы, которая:
- 💰 Управляет финансами (доходы, расходы, сборы)
- 🚗 Планирует рейсы доставки помощи
- 📦 Ведет склад товаров
- 📢 Генерирует посты для соцсетей
- ⚙️ Управляет справочниками (люди, машины, подразделения)

---

## 🔧 Требования

- Python 3.6+ или Node.js 14+
- Git
- Браузер (Chrome, Firefox, Safari, Edge)
- Интернет (для Firebase)

## 🔐 Первая конфигурация

1. Создайте проект на [Firebase Console](https://console.firebase.google.com/)
2. Получите конфигурационные данные
3. **Откройте `src/js/config.js`**
4. **Замените значения на ваши Firebase ключи**:
```javascript
const firebaseConfig = {
    apiKey: "YOUR_KEY",  // ← Замените
    authDomain: "project.firebaseapp.com",  // ← Замените
    databaseURL: "https://project-rtdb.firebaseio.com",  // ← Замените
    // ...остальное
};
```

## 💡 Первые действия

После входа в систему:

```
1. Справочники (Settings)
   ↳ Добавьте кошельки
   ↳ Добавьте благотворителей
   ↳ Добавьте подразделения

2. Финансы (Finance)
   ↳ Добавьте пожертвование (Income)
   ↳ Просмотрите дашборд

3. Рейсы (Trips)
   ↳ Спланируйте рейс

4. Пресс-центр (Press Center)
   ↳ Создайте пост для соцсетей
```

## 📊 6 основных модулей

### 💰 Финансы
Управление деньгами: доходы, расходы, переводы, целевые сборы

### 🚗 Рейсы
Планирование и отслеживание рейсов доставки помощи

### 🎯 Сборы & Заказы
Целевые сборы денег и товаров, связь с подразделениями

### 📦 Склад
Учет приходов/расходов товаров, финансовая оценка

### 📢 Пресс-центр
Генераторы постов для соцсетей (утро, обед, каталоги, финотчеты)

### ⚙️ Справочники
Управление системой (кошельки, люди, подразделения, транспорт)

## 🐛 Частые проблемы

### Ошибка: "Cannot GET /"
```bash
# → Убедитесь, что сервер запущен
python -m http.server 8000

# → Откройте http://localhost:8000/
```

### Данные не сохраняются
```bash
# → Проверьте Firebase конфиг в src/js/config.js
# → Проверьте интернет соединение
# → Откройте консоль браузера (F12) для ошибок
```

### Приложение не загружается
