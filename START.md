## 🔧 ШАГ 0: ПОДГОТОВКА FIREBASE

**⚠️ КРИТИЧНО ПЕРЕД ПРОДАКШЕНОМ:**

```bash
# Откройте: src/js/config.js
# Найдите эту строку:
const firebaseConfig = {
  apiKey: "YOUR_API_KEY", // ← ЗАМЕНИТЕ
  authDomain: "YOUR_PROJECT.firebaseapp.com", // ← ЗАМЕНИТЕ
  databaseURL: "https://YOUR_PROJECT-rtdb.firebaseio.com", // ← ЗАМЕНИТЕ
  // ... и другие
};

# Получите правильные значения:
# 1. Откройте https://console.firebase.google.com
# 2. Откройте Ваш проект
# 3. Project Settings (иконка шестеренки)
# 4. Копируйте Web SDK config
# 5. Вставьте в src/js/config.js
```

**Для локальной разработки:**
- Используйте Firebase Emulator Suite (опционально)
- Или просто используйте тестовый Firebase проект

## ❓ ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ

### Q: Где мой данные?
**A:** Все данные хранятся в Firebase Realtime Database. Они синхронизируются в реальном времени и сохраняются над сессиям.

### Q: Могу ли я использовать на своей базе?
**A:** Да! Обновьте `src/js/config.js` со своим Firebase проектом.

### Q: Как настроить пользователей?
**A:** Откройте модуль "Справочники" → "👥 Пользователи" → добавить пользователя.

### Q: Откуда берутся пороги "низких остатков"?
**A:** Установлены на 10 единиц товара в модуле "Склад".

### Q: Можно ли экспортировать данные?
**A:** Сейчас нет, но это планируется в будущих версиях.

### Q: Есть ли Telegram бот?
**A:** Нет, но готовое решение описано в [PROMPT.md](PROMPT.md)

### Q: Подходит ли это для мобильного?
**A:** Да! Полностью адаптивный дизайн на все устройства.

### Q: Это бесплатно?
**A:** Да! MIT лицензия с благотворительной клаузулой.

## 📞 ПОДДЕРЖКА

| Проблема | Решение |
|----------|---------|
| Не работает login | Проверьте Firebase конфиг в src/js/config.js |
| Дахні не синхронизируются | Проверьте console (F12) на ошибки Firebase |
| Медленная загрузка | Это локальный сервер - нормально для разработки |
| Ошибка 404 | index.html должен быть в корне |
| Port 8000 занят | Используйте `lsof -i :8000` чтобы найти процесс |
