## 🎉 [1.4.0] - 2026-02-08

### ✨ ДОБАВЛЕНО

#### 🤝 CRM Платформа для благотворителей
- Новый модуль "🤝 CRM - Благотворители"
- Полная карточка благотворителя с историей
- Система рейтинга благотворителей (⭐⭐⭐⭐⭐)
- Анализ активности и уровня вклада
- История всех благотворительных действий
- Массовая рассылка благодарственных писем
- Целевые предложения на основе истории

#### 📜 Благодарственные письма
- Новый модуль "📜 Благодарственные письма"
- 6 профессиональных шаблонов:
  - Официальное благодарственное письмо 📋
  - Краткое спасибо 🙏
  - Подробное благодарство 💝
  - Для юридических лиц 🏢
  - Волонтеру 👥
  - Личное письмо 💌
- Размер A4 (не обрезается при печати)
- Редактируемые шаблоны с переменными
- Скриншоты для отправки в мессенджеры
- Сохранение черновиков

#### 🔐 Электронная подпись (Расширенная)
- Реальная электронная подпись с:
  - Инициалами подписанта
  - Должностью
  - Датой и временем подписания
  - Уникальным кодом подписи (SIG-XXXXX)
  - Визуальной рамкой с цветовым кодированием
- История всех подписей в системе
- Верификация подписей
- Профиль подписанта в каждом документе

#### 🏭 Управление складами
- Поддержка двух складов:
  - Склад на Софийской ул.
  - Склад п. Песочный
- Перемещение товаров между складами
- История всех перемещений
- Автоподстановка "кем передано"
- Создание нового контакта если нет в базе

#### 🖨️ Печатные формы (Профессиональные)
- Печать приходных документов
- Печать расходных документов
- Печать благодарственных писем
- Печать отчетов по сборам
- Печать карточек благотворителей
- Все документы с электронной подписью
- QR-коды для верификации документов
- Правильное форматирование и таблицы

#### 🎨 Интерфейс и дизайн
- Полный редизайн с яркими цветами
- 6 цветовых схем:
  - 💙 Доход (синий #2563eb)
  - 💚 Приход (зелёный #16a34a)
  - 🧡 Расход (оранжевый #ea580c)
  - ❤️ Убытки (красный #dc2626)
  - 💜 Волонтеры (фиолетовый #7c3aed)
  - 💎 Премиум (цвет #0891b2)
- Анимации при переходах
- Улучшенная типография
- Лучшая контрастность
- Профессиональные иконки и эмодзи

#### 📊 Отчетность
- Информационная справка об оказанной помощи
- Расширенные отчеты по благотворителям
- Еженедельные и ежемесячные отчеты
- Анализ эффективности сборов
- Статистика по складам
- Графики и аналитика

#### 📝 Система ответственных
- Ответственные лица для каждой операции
- История ответственных
- Подпись ответственного на операциях

#### 🌍 Локализация
- Везде указан 2026 год
- г. Санкт-Петербург во все документы
- Местная адресация
- Местные коды и номера
- Русский язык (полностью)

#### 🎯 Функциональные улучшения
- ВСЕ кнопки теперь работают (нет заглушек)
- Волонтеры = Благотворители (разница только в типе)
- История версий в настройках
- Информация о программе в меню

### 🔧 ИЗМЕНЕНО

- Обновлены цветовые переменные CSS
- Расширена Firebase конфигурация
- Улучшена структура базы данных
- Обновлена навигация (добавлены 2 новых модуля)
- Расширен глобальный state приложения

### ⚠️ ВАЖНЫЕ ИЗМЕНЕНИЯ

- `http://localhost:8000` - используется Firebase v10.7.0
- База данных: https://blago-a6270-default-rtdb.firebaseio.com
