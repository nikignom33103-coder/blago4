## 🎯 Что это?

Полнофункциональный веб-портал для управления волонтерской организацией "Благо дарить!" (Help Give!). Система позволяет организовать работу по:

- 💰 **Управлению финансами** - отслеживание доходов, расходов и переводов
- 🚗 **Планированию рейсов** - координация поездок с назначением водителей и техники
- 📦 **Управлению сборами** - создание целевых сборов и отслеживание прогресса
- 🏭 **Инвентаризации склада** - учет передвижения товаров
- 📰 **Генерации контента** - автоматическое создание постов для социальных сетей
- 👥 **Справочникам** - управление данными о волонтерах, кошельках, машинах и воинских частях
- 📊 **Аналитике** - просмотр KPI и статистики в реальном времени

## 🎨 Основные возможности

### 📊 7 Главных модулей

```
Дашборд       → KPI метрики (доход, расход, баланс, рейсы, сборы)
Финансы       → Управление доходами, расходами и переводами
Рейсы         → Планирование и отслеживание поездок
Сборы         → Целевые сборы с отслеживанием прогресса
Склад         → Инвентаризация товаров и их движение
Пресс-центр   → Генератор постов для социальных сетей
Справочники   → Кошельки, доноры, части, машины, пользователи
```

### ✨ Ключевые особенности

- ✅ **Real-time синхронизация** - данные обновляются в реальном времени через Firebase
- ✅ **Адаптивный дизайн** - работает на всех устройствах (desktop, tablet, mobile)
- ✅ **Безопасность** - Firebase Authentication + user-scoped данные
- ✅ **Без фреймворков** - чистый JavaScript, без зависимостей
- ✅ **Модульная архитектура** - каждый модуль независим
- ✅ **Multi-tab** - интерфейс с вкладками внутри модулей
- ✅ **Forms validation** - валидация форм перед отправкой
- ✅ **Dark sidebar** - современный UI с боковым меню

## 💡 Примеры использования

### Добавить новый доход

```
1. Откройте "Финансы" → "Доход"
2. Выберите источник (wallet)
3. Выберите тип донора (физ.лицо/организация)
4. Введите сумму
5. Нажмите "Добавить"
→ Данные сохранены в Firebase ✅
```

### Планировать рейс

```
1. Откройте "Рейсы" → "Планирование"
2. Введите пункт назначения и дату
3. Выберите водителя и машину
4. Нажмите "Создать рейс"
→ Рейс отображается в списке ✅
```

### Генерировать пост

```
1. Откройте "Пресс-центр"
2. Нажмите на кнопку генератора (🌅🌞🛋️💰)
3. Нажмите "Скопировать"
→ Пост в буфере обмена ✅
```

## 🆘 Часто задаваемые вопросы

**Q: Где мои данные?**  
A: В Firebase Realtime Database. Они синхронизируются в реальном времени.

**Q: Как использовать на своей базе?**  
A: Обновите `src/js/config.js` со своим Firebase проектом.

**Q: Это платно?**  
A: Нет! MIT лицензия (open source), Firebase имеет бесплатный tier.

**Q: Можно ли модифицировать?**  
A: Да! Просто задачи - ознакомьтесь с [CONTRIBUTING.md](CONTRIBUTING.md).

**Q: Поддерживается ли мобильный?**  
A: Да! Полностью адаптивный дизайн.

**Q: Нужны ли какие-то услуги?**  
A: Только Firebase (бесплатный) и хостинг (Netlify/Vercel/GitHub Pages - бесплатные).
