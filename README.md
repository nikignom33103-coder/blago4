## 🎯 7 ОСНОВНЫХ МОДУЛЕЙ

### 1. 📊 **ДАШБОРД** - Главная панель
- Общая статистика системы в реальном времени
- Суммы доходов, расходов, баланс, количество благотворителей

### 2. 💰 **ФИНАНСЫ** - Учет денежных средств
- Добавление доходов и расходов
- История всех транзакций с датами
- Автоматический расчет баланса

### 3. 🏭 **СКЛАД** - Управление товарами
- Учет товаров на 2 местах (Софийская ул., Песочный)
- Таблица с количеством и датами

### 4. 🤝 **CRM** - База благотворителей
- Управление благотворителями с рейтингами (⭐⭐⭐⭐⭐)
- Рейтинг зависит от размера вклада

### 5. 📰 **ПРЕСС-ЦЕНТР** - Новости и события
- Публикация новостей, событий, отчетов
- Категоризация публикаций
- История всех новостей

### 6. 📜 **БЛАГОДАРСТВЕННЫЕ ПИСЬМА** - Шаблоны писем
- 3 готовых шаблона (официальное, краткое, подробное)
- Редактирование и печать
- Сохранение в базу

### 7. ⚙️ **СПРАВОЧНИКИ** - Настройки и администратор
- Информация о системе
- Админ-панель для управления пользователями (только администраторы)
- Добавление, удаление, просмотр пользователей

## 👨‍💼 АДМИНИСТРАТОР

### Создание администратора
1. Перейди на https://nikignom33103-coder.github.io/blago4/init-db.html
2. Нажми "ВАРИАНТ 1: Только администратор"
3. Получишь: **Никитин / 1166**

### Управление пользователями
1. Войди как администратор (Никитин)
2. Перейди в **Справочники → Администратор**
3. Добавляй новых пользователей с именем, паролем, email и ролью

### Разделение прав
- **Администратор:** Видит всё + управляет пользователями
- **Пользователь:** Видит только рабочие модули (без админ-панели)
