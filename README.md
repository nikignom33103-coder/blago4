# 🎯 Портал "Благо дарить!" - Система управления волонтерской помощью

Полнофункциональный веб-портал для управления волонтерской группой, оказывающей гуманитарную помощь участникам СВО.

## 📋 Краткое описание

**Благо дарить!** - волонтерская инициатива, которая собирает гуманитарную помощь и финансовые средства для доставки на фронт. Этот портал - интегрированная система для управления всем циклом операций.

## ✨ Основные модули

### 💰 **Управление финансами**
- Учет доходов (пожертвования от физ. лиц, организаций, партнерских групп)
- Управление кошельками (Т-Банк, Сбербанк, наличные, бонусы)
- Целевые сборы и финансовые отчеты
- Учет расходов и переводы между кошельками

### 🚗 **Управление рейсами**
- Планирование рейсов с указанием города, даты, водителя
- Управление парком транспорта
- Распределение помощи по подразделениям
- Отчеты по выполненным рейсам

### 🎯 **Сборы и заказы**
- Целевые сборы денег и товаров
- Создание заказов для подразделений
- Ссылки на маркетплейсы (Wildberries, Ozon, Яндекс.Маркет)
- Прогресс-бары и статистика

### 📦 **Управление складом**
- Учет приходов товара от благотворителей
- Категоризация (медикаменты, одежда, продукты, оборудование)
- Расходование товара на рейсы и подразделения
- Финансовая оценка запасов

### 📢 **Пресс-центр**
- 🌅 Генератор утренних постов с целевым сбором
- 🌞 Генератор обеденных постов (истории, благодарности)
- 🛋️ Магазин на диване (каталог заказов с ссылками)
- 💰 Финотчеты для прозрачности
- 📚 Архив черновиков постов

### ⚙️ **Справочники и настройки**
- Управление кошельками, благотворителями, подразделениями
- Справочник транспорта и пользователей
- Система управления доступом

## 🛠️ Технологический стек

- **Frontend**: HTML5, CSS3, JavaScript ES6+, Responsive Design
- **Backend**: Firebase Realtime Database, Firebase Authentication
- **Инфраструктура**: GitHub Pages / Netlify, Firebase

## 🚀 Быстрый старт

```bash
git clone https://github.com/nikignom33103-coder/blago4.git
```

## 📱 Рабочий процесс

### Получение финансирования
1. Финансы → Доход → Добавить пожертвование
2. Сборы → Целевой сбор → Создать новый
3. Пресс-центр → Генератор постов → Поделиться

### Планирование рейса
1. Рейсы → Планирование → Создать
2. Сборы → Связать с рейсом
3. Склад → Проверить остатки
4. Рейсы → Распределить подразделениям

### После рейса
1. Финансы → Расход → Зафиксировать расходы
2. Склад → Расход → Указать доставленные товары
3. Пресс-центр → Финотчет → Создать отчет

## 🔐 Безопасность

- Firebase Authentication (email/password)
- HTTPS для всех подключений
- Контроль доступа по uid пользователя
- Валидация данных на клиенте и сервере
- Полный аудит всех операций (timestamp, uid)
