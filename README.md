## 🎯 6 ОСНОВНЫХ МОДУЛЕЙ

### 1. 📊 **ДАШБОРД**
- Общая статистика системы
- Показатели доходов, расходов, баланса
- Количество благотворителей
- Быстрый обзор всей системы

### 2. 💰 **ФИНАНСЫ**
- Добавление доходов и расходов
- Категоризация операций
- История всех транзакций
- Автоматический расчет баланса

**в том числе:**
- Описание каждой операции
- Дата операции
- Сумма в рублях
- Фильтрация по типам

### 3. 🏭 **СКЛАД**
- Управление двумя складами:
  - Софийская ул.
  - Песочный
- Прием товаров
- Учет остатков
- История всех товаров

**в том числе:**
- Название товара
- Количество
- Место хранения
- Дата добавления

### 4. 🤝 **CRM - БЛАГОТВОРИТЕЛИ**
- База данных всех благотворителей
- Отслеживание вкладов
- Автоматический рейтинг (⭐⭐⭐⭐⭐)
- Контактная информация

**в том числе:**
- ФИО/название организации
- Email контакт
- Сумма вклада
- Рейтинг зависит от суммы:
  - 100,000+ ₽ = ⭐⭐⭐⭐⭐
  - 50,000+ ₽ = ⭐⭐⭐⭐
  - 10,000+ ₽ = ⭐⭐⭐
  - < 10,000 ₽ = ⭐⭐

### 5. 📜 **БЛАГОДАРСТВЕННЫЕ ПИСЬМА**
- 3 готовых шаблона:
  - Официальное
  - Краткое
  - Подробное
- Редактирование текста
- Печать на принтер (A4)
- Сохранение писем в базе

**в том числе:**
- Выбор шаблона
- Редактирование текста
- Предпросмотр
- Печать (Ctrl+P)
- История сохраненных писем

### 6. ⚙️ **СПРАВОЧНИКИ**
- Информация о системе
- Список складов
- **АДМИН-ПАНЕЛЬ** для администраторов:
  - Добавление новых пользователей
  - Управление ролями (админ/пользователь)
  - Удаление пользователей
  - Список всех пользователей

## 👨‍💼 АДМИНИСТРАТОР

### Для администраторов доступно:

#### ✅ Добавление нового пользователя
Перейдите в **Справочники → Администратор** и заполните форму:
- **Имя пользователя** (например: Петров)
- **Пароль** (минимум 4 символа)
- **Email** (для контактов)
- **Роль** (администратор или обычный пользователь)

Нажмите "✅ ДОБАВИТЬ ПОЛЬЗОВАТЕЛЯ"

#### ✅ Просмотр всех пользователей
Все пользователи видны в таблице с возможностью удаления.

#### ✅ Удаление пользователя
Нажмите кнопку "Удалить" рядом с пользователем.

### Для обычных пользователей:
- Видят только 5 модулей: Дашборд, Финансы, Склад, CRM, Письма
- Админ-панель скрыта
- Не могут добавлять пользователей

## ❓ ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ

**Q: Как добавить нового пользователя?**
A: Войдите как администратор, перейдите в Справочники → Администратор и добавляйте пользователей.

**Q: Где хранятся данные?**
A: В Firebase Realtime Database (защищенной облачной базе данных Google).

**Q: Могу ли я использовать это офлайн?**
A: Нет, требуется интернет подключение для работы с Firebase.

**Q: Какой максимум пользователей?**
A: Firebase поддерживает сотни тысяч пользователей.

**Q: Как сбросить пароль?**
A: Администратор может удалить пользователя и создать его заново.
